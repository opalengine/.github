# Getting help

- **Found a bug?** Open an issue in the repository concerned with the **Bug report** form.
- **Want a feature or change?** Use the **Feature request** form.
- **A security problem?** Don't open an issue. Follow [SECURITY.md](SECURITY.md).
- **Anything else** (questions, collaboration, something that isn't a bug): write to
  hello@opalengine.com.

Please search existing issues first; adding detail to an open issue beats opening a duplicate.
We're a small team and answer as time allows.
