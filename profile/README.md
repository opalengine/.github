# Opal Engine

An engineering collective. We build the tools we want for working with AI, then put them out in the open.

**What we're into:** agents doing real delivery work without stepping on each other, running models on hardware you already own, and guardrails built into the platform rather than bolted on after.

**What we're doing now:**

- **cinder** answers Cloudflare's question of what git should look like with a dozen agents on one repo: leases before code, graded model judgments, signed merges. [Code](https://github.com/brinkercode/cinder) · [write-up](https://opalengine.com/blog/what-a-dozen-agents-taught-us-about-git)
- **Relay** is in progress: pooling GPU memory across a few machines into one OpenAI-compatible endpoint. It isn't released yet.

**Open for collaboration.** If you're putting agents into real pipelines, or want to help build any of this out, write to hello@opalengine.com.
