# Opal Engine

An engineering collective working on how AI gets put to work.

We focus on putting agents into real workloads at scale, effectively and securely. We build applications that help developers get more out of models of every kind, and alternatives to everyday tools that we would actually use ourselves. What we make goes out in the open.

**Open for collaboration.** If you're working on the same problems, or want to help build, write to hello@opalengine.com.
